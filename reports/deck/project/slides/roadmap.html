WHAT TO SAY: Here is the plan for the talk. First, what we built: the downloader, a test server whose behaviour we control, and how we make the comparisons fair. Then five tests. One: our downloader against aria2 on a server that starts slow and then speeds up. Two: real recorded mobile networks, where the speed jumps around. Three: a server we built that punishes too many connections, so the best setting genuinely changes during the download. Four: learning controllers that learn when to change the dials. Five: real public servers on the internet. At the end we put the comparison with aria2 in one chart, say what is new, list the limitations, and show a short live demo. IN SIMPLE WORDS: Each test gives adaptation a better chance than the one before. TERMS ON THIS SLIDE: • CDN (content delivery network): servers spread around the world that deliver files from a nearby location. • Learning controller: a program that learns, by trial and error, when to change N and S.
