When does adapting a download while it runs actually help?

A controlled study of parallel HTTP downloads under changing network and server conditions, against aria2 and other download tools

Sourajyoti Basak · Shwetank Shrijan · Ayush Konar

WHAT TO SAY: Good morning. We are Sourajyoti, Shwetank and Ayush. Our project asks a simple question: when a big download is running and the network or the server changes, does it help to change how the download is split up while it runs? IN SIMPLE WORDS: Download managers speed up big downloads by asking for many pieces of the file at the same time. We built our own download manager that can change how many pieces it fetches at once, and how big they are, in the middle of a download, and we tested whether that actually makes downloads faster than popular tools like aria2. TERMS ON THIS SLIDE: • Parallel HTTP download: fetching several parts of one file at the same time over separate connections. • aria2: a widely used open-source download manager, our main comparison.
