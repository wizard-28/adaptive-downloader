WHAT TO SAY: How do the AI agents compare with aria2 and big pieces? This chart puts all the times for the cap-from-8-seconds test side by side. Big 32 MiB pieces took 50.9 seconds and aria2 52.6. The best AI agent took 64.8 seconds, and the simple drop rule 61.9. The reason is the server rule from earlier: a request keeps the speed it had when it started. Big pieces all start before the cap, so they keep the fast speed. An agent using 1 MiB pieces starts almost every request after the cap, so it always gets the slow speed, however cleverly it picks the number of connections. We checked that this is the reason: on a version of our server that re-checks the speed during each response, the big-piece setting slowed from 50.9 to 67.4 seconds. IN SIMPLE WORDS: Under this cap, “start big pieces early” beats “adapt cleverly”, and that depends on how the server sets speeds. TERMS ON THIS SLIDE: • Request-start rule: the server fixes a response’s speed when the request arrives. • Server that re-checks speed: a control version of our server that updates each response’s speed while it runs. • First retrained agent / broadly trained agent / agent picking N and piece size: the three AI agents from the previous two slides.
