To remove the handicaps of the earlier head-to-heads, the frozen DQN v6 agent was also run on the capped server with a 512~MiB file, on the fixed engine, starting either at one connection (as trained) or at 16 (as aria2 does). The protocol was written down before the first run: 2 scenarios $\times$ 5 arms $\times$ 5 blocks, with 0 invalid runs. The agent was not retrained for this server.
