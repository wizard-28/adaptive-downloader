\section{Top-level layout}
\begin{lstlisting}
AGENTS.md, CLAUDE.md      working rules for contributors (human or AI)
queue.md                  running work queue
go.mod                    module adaptivedl, Go 1.27.1 (only dependency: Gonum)
cmd/                      command-line programs (below)

testdata/<study>/         one folder per study (later ones: protocol.md, manifest, raw/, analysis/, tools/)
tools/claims_check.py     recomputes every paper number from raw artifacts
reports/                  paper draft, reviews, viva material, this handbook
docs/                     PROJECT_CONTEXT.md (living log), REPRODUCING.md, notes
\end{lstlisting}

\section{Reproducing}
\begin{lstlisting}[language=bash]
go build ./... && go vet ./... && gofmt -l internal cmd
go test ./...                      # add -race; -p 1 for replay tests
pytest python/tests                # Python unit tests
python3 tools/claims_check.py      # 220 numbers from raw artifacts
python3 tools/test_claims_check.py # checker self-test
python3 testdata/<study>/tools/analyze.py   # re-run one study's analysis
python3 reports/handbook/make_figs.py       # this handbook's new figures
\end{lstlisting}
Live runs need root for \code{tc netem}, aria2 1.37.0 and (for traces) Mahimahi; see \code{docs/REPRODUCING.md}. Never run timing-sensitive experiments while the machine is loaded.
